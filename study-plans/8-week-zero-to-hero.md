# 8-Week 1050→1350 (1.5-2h/day)

## Weeks 1-2 — Base (no full mocks)
- Daily: 1 QBank Easy set (11Q) alternating RW/Math + Anki 10.
- RW: boundaries → verbs. Math: linear → systems (Panda Ch1-4).
- Sun: redo week's misses. Goal: finish Easy 85%+.

## Weeks 3-4 — Skill Up
- Daily: Medium sets (11Q timed) + Desmos 10 min.
- RW: evidence + transitions. Math: quadratics + ratios.
- Sat W4: Bluebook Test 2 full + log. Goal: 1200-1250 mock.

## Weeks 5-6 — Intensify
- Daily: Hard sets 2x/week, Medium 3x/week. AI review same day.
- RW: vocab + cross-text. Math: functions + stats + geometry basics.
- Sat: Bluebook Test 3. Redo misses Sun. Goal: hard M2 reached.

## Weeks 7-8 — Mock Season
- 1 Bluebook/week (Tests 4-5), review next day (2h).
- Mon-Fri: weak-tag drills only (top 3 from log).
- Final 5 days: Bluebook newest, checklists, taper. Docs + laptop check.
Milestones: W2 1150 sets, W4 1250 mock, W6 hard module, W8 target ±50 x2.
