# 12-Week 900→1300+ (1-2h/day, school-friendly)

## Phase 1 W1-4 — Foundations (no mocks, confidence first)
- Kaplan/Princeton Ch 1-6 + Khan basics (30 min/day).
- Math: pre-algebra → linear (Panda Ch1-3). RW: sentences → boundaries.
- Anki 10/day (roots + formulas). Desmos 5 min/day (graph lines).
- Goal: Easy sets 80%+, know format cold.

## Phase 2 W5-8 — Technique
- Panda Ch4-8 + Meltzer Grammar Ch1-5 (1 ch / 2 days).
- Daily 11Q Medium timed. Sat biweekly QBank section + log.
- W8: Bluebook Test 1 full. Goal: 1150+ mock, timing ok.

## Phase 3 W9-12 — Performance
- W9-10: Hard sets 2x/week + Bluebook Test 2-3. Desmos fluency (systems/quadratics).
- W11: Bluebook Test 4 + top-3 tag blitz (40Q each weak tag).
- W12: Bluebook 5 (save 6 if retest planned), checklists, taper. Sleep + docs.
Full-time? Compress to 8 weeks (double daily sets). <1h/day? Extend Phase 1 to 6 weeks — don't rush mocks.
