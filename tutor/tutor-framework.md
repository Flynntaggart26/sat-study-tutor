# Tutor Framework — Human Tutors, Parents, Clubs (v2)

## Diagnostic (60 min, script)

1. 15 min interview: goal score + date + past Bluebook/PSAT + h/day + laptop/Bluebook ready? Weak feeling?
2. 20 min mini-set: 11 RW Medium (14 min) + 11 Math Medium (20 min), timed, no help. Mark + tag together.
3. 15 min triage: name top 3 tags (e.g. boundaries, systems, misread). Show error taxonomy C/T/careless/misread.
4. 10 min plan: assign study-plans file + tracker link + homework (3 sets + Anki). Set next date.

Output: 1-page sheet — scores, 3 tags, plan file, homework due.

## Lesson Templates

**60-min Math (weak tag, e.g. quadratics):**
- 10 review: student explains 3 homework misses (not tutor).
- 20 timed: 11Q same tag, strict.
- 25 live solve: think-aloud, max 3 patterns, Desmos + algebra both, student re-solves 2 blind.
- 5 assign: redo misses + 11Q new + 5 Anki.

**60-min RW (e.g. boundaries):**
- 10 rule check: student recites rule + 2 examples.
- 20 timed: 11Q conventions.
- 25 evidence review: quote lines, name trap per miss.
- 5 assign: rewrite 5 sentences + 11Q.

**90-min Mock review:**
- Student pre-logged (Q#, my vs correct, tag). Tutor validates tags, re-times flagged Qs.
- Focus: timing strategy (guess+flag) + careless protocol, not just content.
- End: updated top-3 tags + next-week sets.

## Feedback Rules

- Max 3 patterns/session. More = forgotten.
- Sequence: show miss → ask “why?” → teach rule → student re-solves → new similar Q.
- End every lesson: 1 win + 2 written actions + photo of notes to tracker.
- Homework policy: no redo = no new set. 3 sets/week min. Anki screenshot weekly.

## Progress

Every 4 lessons: timed 22Q re-test same tags. Expect +30-50 section points / month at 8h/week with feedback. If flat 6 weeks → double feedback (2x/week or daily AI), not hours.
