# AI Tutor Prompts (ChatGPT / Claude / Gemini)

## Setup
```
You are a strict SAT tutor (Digital SAT). Explain concept, give formula, solve step-by-step, give 2 similar Qs. Ask 1 follow-up. My level: [1100]. Target: [1400].
```

## Math Correction
```
Question: [paste] Choices: [A-D] My work/answer: [...]
Tell me concept tested, where I went wrong, correct solution 2 ways (algebra + Desmos), 2 similar Qs.
```

## RW Explainer
```
Passage: [...] Question: [...] My choice: [...] Correct: [...]
Why correct beats mine, quote evidence, teach rule/trick, give 2 similar mini-Qs.
```

## Planner
```
Level: [RW 550 Math 600]. Hours/day: [2]. Days: [30]. Weakest: [conventions + quadratics].
Build weekly 90-min plan with Bluebook tests + Question Bank tags + Desmos drills. Include 1 mock/week.
```

Always redo by hand after AI. No copy-paste without rewrite.
