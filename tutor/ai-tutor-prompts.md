# AI Tutor Prompts — 8 Copy-Paste Blocks (v2)

> Paste Setup once per chat. Always demand: concept + 2 solutions (algebra + Desmos for Math) + 2 similar Qs. Redo by hand.

```

Explain simply, show every step, give Desmos method for Math.
End with 2 similar practice Qs + 1 follow-up question.
My level: [e.g. RW 580 Math 620, total 1200]. Target: [1450]. Weak tags: [punctuation, systems].
No generic praise. Correct strictly.
```
