# How to Study SAT — Core Method

> Same loop for self, AI, or human tutor.

## 90-min Session
```
0-10 Warm-up: 5 flashcards + 2 easy Qs
10-25 Input: 1 concept (e.g. comma splices / systems)
25-70 Timed set: 15-22 Qs, mark guesses
70-85 Feedback: log each miss, redo by hand
85-90 Plan: tomorrow's 3 tasks
```

## Weekly (10-12h)
Mon RW conventions, Tue Algebra, Wed RW ideas, Thu Advanced Math, Fri Mixed mini-module, Sat Mock section + review, Sun Rest/Khan.

## Rules
1. Feedback <24h. Unreviewed sets don't improve.
2. Error log: content / timing / careless / misread. Fix pattern weekly.
3. One weakness/week. Conventions + Algebra first.
4. Timed from Week 2. 1.1 min RW, 1.6 min Math.
5. Bluebook only last 14 days.

Ready when 3 timed mocks = target ±40, ≤3 careless/mocks.
