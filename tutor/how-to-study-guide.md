# How to Study SAT — Core Method (v2)

> One loop for self-study, AI tutor, or human tutor. 90 minutes beats 3 unfocused hours.

## The 90-Minute Session (copy this)

```
0-10   Warm-up: 5 Anki (roots/formulas) + 2 easy Qs from yesterday's misses
10-25  Input (1 concept only): read 4 pages or watch 1 video at 1.25x, take 5-line notes
       Example: "comma splice = two independents joined by comma → fix with . ; : + FANBOYS"
25-70  Timed set: 15-22 Qs, Bluebook/QBank, mark guesses with *
       RW: 11 Q / 14 min. Math: 11 Q / 20 min. No notes during set.
70-85  Feedback (most important 15 min):
       1. Mark. 2. Tag each miss: [C]ontent / [T]iming / [Careless] / [Misread]
       3. Redo by hand without looking. 4. Write 1-line fix ("underline solve-for-2x")
85-90  Plan: write tomorrow's 3 tasks in tracker. Prep Bluebook link + calculator.
```

## Weekly Rhythms

**1h/day (minimum viable, 7h/week):**
Mon RW set, Tue Math set, Wed review misses only, Thu opposite set, Fri mixed 15Q, Sat biweekly section, Sun off.

**2h/day (recommended, 14h/week):**
Add daily 15-min Desmos + 15-min Anki. Sat full section + Sunday review. 1 mock / week last month.

**4h/day (summer sprint):**
AM timed section + PM redo + AI review. Full mock Sat, full review Sun. Cap at 6 days — 1 rest day mandatory.

## Error Taxonomy (use these tags)

| Tag | Example | Fix |
|-----|---------|-----|
| Content | Don't know vertex form | Learn concept, 10 Qs same tag |
| Timing | Knew but ran out | Guess+flag drill, 1.1/1.6 min per Q |
| Careless | Solved for x not 2x, sign slip | Checklist + plug-back every Q |
| Misread | Radius vs diameter, % of vs increase | Underline ask + units every step |

Review Friday: count tags. Top tag = next week's sole focus.

## Topic Order (cheapest points first)

1. Week 1-2: Punctuation + linear equations/systems
2. Week 3-4: Verbs + transitions + ratios/percents
3. Week 5-6: Evidence/inference + quadratics/functions
4. Week 7+: Geometry/trig + hard QBank + Bluebook hard modules

Do not study hard trig before algebra is 90%+.

## Readiness Checklist (book when all true)

- [ ] 3 timed Bluebook mocks within ±40 of target (2 newest included)
- [ ] ≤3 careless + ≤2 misread per full mock
- [ ] Conventions + Algebra tags <20% of misses
- [ ] Can finish RW with 3 min + Math with 5 min to review flagged
- [ ] Desmos: systems + quadratics graphed without help

## Tool Stack (max 4)

Bluebook + QBank + Khan + 1 (1600.io OR UWorld) + Desmos + Anki. Delete rest.
Anki: 10 new/day max, only from your misses. Front: trigger ("its vs it's") → Back: rule + your sentence.
