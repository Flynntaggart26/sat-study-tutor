# Math — Algebra (Heart of Algebra, ~35%)

Linear equations/inequalities, systems, functions notation. Easiest points to 700+.

## Must-master
- Solve `ax+b=c`, isolate fast, check by plugging.
- Systems: substitution + Desmos intersection (graph both, read point).
- Linear word problems: define variable, write equation, units check.
- Functions: f(x) evaluation, interpreting slope/intercept in context.

## Desmos checks
Graph line, table values, intersect systems. Always verify multiple-choice by plugging options.

## Drill
College Panda Ch 1-8 + Question Bank Easy/Medium 20-Q sets. Target 90%+ before Advanced.
