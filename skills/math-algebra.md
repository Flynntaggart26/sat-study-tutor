# Math — Algebra + Functions (v2, ~35% Math)

Heart of Algebra = fastest to 700 Math. Master until 90%+ Medium.

## Checklist per Q

1. Define variable + write equation (don't compute in head).
2. Solve, then Desmos/plug-back check.
3. Underline what they ask: `x`? `2x`? `x+1`? Units?

## Core Patterns

- **Linear:** `ax+b=c` → isolate. Word problem: `total = base + rate×n`. Check units.
- **Systems:** `y=mx+b` both → Desmos: graph y1, y2 → click intersection. Faster than substitution for 80%.
- **Inequalities:** flip sign when ×/÷ negative. Graph on Desmos to verify range.
- **Functions:** `f(3)` = plug 3. Slope = rate, intercept = starting value. `f(x)=...` table test with x=0,1,2.

## Desmos for Algebra (do daily)

- Type `y1=2x+3`, `y2=-x+5` → intersection = solution.
- Table: add table, enter x choices A-D, see which satisfies.
- Slider `m` in `y=mx+2` to feel slope.
