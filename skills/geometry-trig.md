# Geometry & Trigonometry (v2, ~15%)

Low volume, high “draw it” payoff. Always sketch + label, even if figure given.

## Memorize (test gives volume, not these shortcuts)

- Triples: 3-4-5, 6-8-10, 5-12-13. 45-45-90: `x,x,x√2`. 30-60-90: `x,x√3,2x` (short, long, hyp).
- Circle: `(x-h)²+(y-k)²=r²` center (h,k) radius r. Area πr², circumference 2πr. Arc = fraction × circumference.
- Angles: triangle 180°, straight 180°, around point 360°. Parallel lines → alternate equal.
- Trig: SOHCAHTOA. `sin=opp/hyp, cos=adj/hyp, tan=opp/adj`. For complementary: sin(x)=cos(90-x).
- Area/volume given on test reference — practice finding which to use, not memorizing.

## Method

1. Redraw small, label all numbers/angles.
2. Mark right angles, equal sides.
3. Plug numbers for variables (e.g. let x=2) to test choices.
4. Desmos geometry check for coordinate Qs.

## Drill

1 set/week (8 Q). Time 15 min. Make triple/circle cards. Miss = redraw correctly + write rule.
