# Best Sources for SAT — Master List (v2)

> 35+ sources rated by ROI. Digital SAT only (2024+). Tested 2026. Free path to 1400 marked 🆓.

**How rated:** ★ = points-per-hour + officialness + explanation quality. Levels: 🟢 900-1150 / 🟡 1150-1350 / 🔴 1350-1600.

## 🏛️ Tier 1 — Official (use first, use most)

| Source | Best For | Cost | Level | How to use |
|--------|----------|------|-------|------------|
| **Bluebook** — https://bluebook.collegeboard.org + 6 tests | Only real adaptive mocks | 🆓 Official | All | Full mocks only, morning, save 5-6 newest for final 10 days. Review next day. |
| **[Question Bank](https://satsuitequestionbank.collegeboard.org)** — 2000+ Qs | Drill by tag (e.g. boundaries, systems) | 🆓 Official | All | 11-Q timed sets, one tag at a time. Easy→Hard filter. |
| **[Khan Academy Digital SAT](https://www.khanacademy.org/digital-sat)** | Adaptive course linked to Bluebook | 🆓 | 🟢🟡 | Link scores → 30 min/day path. Best for <1300. |

Never pay for mocks before finishing free 6. Protocol: [`practice-tests.md`](practice-tests.md).

## 🚫 Avoid List

- Pre-2024 paper SAT books for RW (old long passages, wrong Q types).
- “Leaked QAS packs” (copyright + pre-Digital, misleading curves).
- Non-adaptive PDFs in final 14 days (wrong pacing).
- Vocab memorizing 1000 words (SAT tests logic + 200 roots, not dict).
- Calculator-only apps that ban Desmos practice.
