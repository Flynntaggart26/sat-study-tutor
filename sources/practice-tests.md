# Practice Tests — Where & How

## Ranked
1. Bluebook Practice Tests 1-6 (adaptive, official)
2. College Board Question Bank timed sets (by skill)
3. Princeton Review / Kaplan mocks (stamina, harder curve)
4. College Panda 10 (extra, 1450+ polish)

## Protocol
- Same time as real (morning), laptop charged, Bluebook updated, phone away.
- RW Module 1 (32 min, 27 Q) → RW Module 2 → break 10 → Math M1 (35 min, 22 Q) → Math M2.
- No pause. Mark for review only if <30 sec left to guess.
- Score immediately, log every miss: content / timing / careless / misread.

## Schedule
- <1200: 1 mock / 2 weeks
- 1200-1400: 1 mock / week
- Last 2 weeks: 2 mocks / week (save newest Bluebook for last)

Never mock without next-day review. Unreviewed mocks = wasted.
