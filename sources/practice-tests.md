# Practice Tests — Bluebook Simulation Protocol (v2)

## Order (use in this order)

1. **Bluebook Tests 1-6** (official adaptive) — Tests 1-2 for diagnostic + early, 3-4 mid, 5-6 final 10 days.
2. **QBank timed sets** (by tag) — daily driver between mocks.
3. **Princeton/Kaplan mocks** — stamina only, ignore exact scaled score (±50 noise).
4. **Panda 10** — extra hard volume for 1500 chase after Bluebook done.

## Simulation Checklist (do all)

- [ ] Morning (same as real), 2h15 blocked, laptop 100% + charger.
- [ ] Bluebook updated, calculator + Desmos tested (1 graph).
- [ ] Phone in another room, notifications off, scratch paper + pencil.
- [ ] RW M1 32:00 → M2 32:00 → 10:00 break (stand, water) → Math M1 35:00 → M2 35:00.
- [ ] Guess every Q, flag if >90s RW / >2 min Math, review flagged only with time left.
- [ ] Score immediately, log tags same day, full review next morning (2h max).

## Scoring Notes

- Bluebook scaled is accurate ±30. Third-party scaled ±50 — use raw + tags instead.
- Track: total + RW/Math + hard-M2 reached? (Y/N) + careless count. Hard M2 = progress even if total flat.
- Save newest Bluebook for last — retaking seen test inflates +40-60. Mark retakes.

## Cadence

<1200: 1/2 weeks. 1200-1400: 1/week. Last 14 days: 2/week max + taper 2 days before. Never mock sick or midnight — bad data.
