# Websites & Apps — Exact Setup (v2)

- **Khan Academy Digital SAT** — https://www.khanacademy.org/digital-sat — Link College Board account → Import Bluebook scores → Do “Recommended” path 30 min/day. Best <1300. Don’t skip unit quizzes.
- **Question Bank** — https://satsuitequestionbank.collegeboard.org — Create set: Filter skill=Boundaries, difficulty=Medium, n=11 → Timer 14 min → Review explanations → Export misses to Anki. One tag/day.
- **1600.io** — https://www.1600.io — After Bluebook test: enter answers → watch only missed Q videos at 1.25x → redo blind. Free Tests 1-4, paid rest (1 month enough).
- **UWorld SAT** — Hard bank, best explanations for 1350+. Make custom test: 22 Math Hard / 35 min. Read every explanation even if correct (faster method).
- **Desmos Test Mode** — Practice at desmos.com/calculator with test settings. Do `templates/desmos-cheatsheet.md` 1-15 in order.
- **Bluebook** — https://bluebook.collegeboard.org — Update weekly. Full-screen, Do Not Disturb, morning. Review within 24h or value halves.
- **Anki** — Deck: “SAT Roots + Formulas + My Misses”. 10 new/day. Front trigger → Back rule + your example. Suspend leeches after 5 fails, relearn via new sentence.
- **r/SAT + Discord** — Search “Bluebook Test X curve” before panic. Verify any non-official answer with QBank.

Stack: Bluebook + QBank + Khan + one (1600.io/UWorld) + Desmos + Anki. Delete rest if unused 7 days.
