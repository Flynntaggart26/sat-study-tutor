# Websites & Apps — How to Use Each

- **Khan Academy Digital SAT** — Link Bluebook scores → do recommended path 30 min/day. Best free adaptive.
- **College Board Question Bank** — Filter by skill/difficulty. Make 20-Q timed sets for weakest tag only.
- **1600.io** — Watch solution only after attempting + logging error. Free for tests 1-4.
- **UWorld** — Hard Math + RW volume. Use explanations to make flashcards.
- **Desmos** — Practice: graph lines/quadratics, solve systems with intersection, check plug-ins. 10 min/day.
- **Bluebook** — Full mocks only, airplane mode, same time as real test.

Max 3 tools + Bluebook. Delete if unused 7 days.
