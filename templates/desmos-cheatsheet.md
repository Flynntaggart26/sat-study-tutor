# Desmos Cheatsheet — 15 Must-Know Inputs

> Built into Bluebook Math. Practice in test mode 10 min/day. If algebra >90s, graph it.
>
> Full companion repo with 30 inputs, 10 worked examples, 15 drills: **[desmos-sat-guide](https://github.com/Flynntaggart26/desmos-sat-guide)** — start with its [`1-page cheatsheet`](https://github.com/Flynntaggart26/desmos-sat-guide/blob/main/cheatsheets/1-page.md).

1. Line: `y=mx+b` — add sliders for m/b to feel slope/intercept.
2. System: `y1=2x+3`, `y2=-x+5` → click intersection = solution (x,y).
3. Parallel check: same `m` = parallel (no solution or infinite if same line).
4. Quadratic: `y=ax^2+bx+c` — roots = x-intercepts, vertex = top/bottom point.
5. Vertex read: hover max/min → coordinates = (h,k).
6. Table test: `+` → Table → enter x=0,1,2 → compare to choices.
7. Plug choices: type each choice equation, see which overlaps.
8. Inequality: `y>2x+1` shades — test point (0,0) to verify side.
9. Circle: `(x-h)^2+(y-k)^2=r^2` — center (h,k), radius r (type to verify).
10. Mean/median: `mean([1,2,9])`, `median([...])` quick check.
11. Exponent: `y=2^x` vs `y=x^2` — graph to see growth, find intersection.
12. Transform: `y=f(x-h)+k` — h right, k up (test with h=2,k=1).
13. Zero method: graph `LHS-RHS` → zeros = solutions.
14. Zoom: `+`/`-` or settings → square grid for geometry accuracy.
15. When NOT to use: simple `2x+4=10` (faster by hand), stats definitions (know median vs mean).
